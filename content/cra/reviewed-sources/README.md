# بازسازی متن مصوبه ۳۳۶-۱

`336-1.txt` همان متن ارسالی مالک سایت است، با حفظ متن آن. اصلاحات قابل بازتولید در `scripts/cra_reviewed_336.py` ثبت شده‌اند و فقط از طریق واردکننده OCR اجرا می‌شوند.

```sh
python scripts/apply-cra-ocr.py content/cra/reviewed-sources/336-1.txt . --reviewed-text
npm run build
node scripts/test-cra-reading.cjs
```

- نسخه PDF تنقیحی رسمی داخل `CRA-Documents(2).zip`، پوشه دارای شناسه `46e982ec`

- این PDF پانزده صفحه دارد، هرچند شماره چاپی صفحات آن هنوز «از ۱۳» است
- جدول ۱۵ ردیفی دو صفحه آخر با جدول نسخه Word تطبیق داده شده و از HTML همان Word، بدون بازنویسی محتوایی، استفاده می‌شود

## مرز اصلاح

این نسخه تنقیح تازه‌ای نیست. متن‌های خط‌خورده از پیوست رسمی با `del` و عبارت‌های جایگزین/افزوده با `ins` نمایش داده می‌شوند. برای مثال حذف شرط اعاده پروانه فقط برای شرکت مخابرات است و نباید به شرط شرکت ایرانسل سرایت کند. بندهای قدیمی ۲۱-۱ و ۲۱-۲ نیز به شکل خط‌خورده حفظ شده‌اند.

تاریخ‌ها، شماره بندها، جای پانوشت‌ها، پرانتزها و مرز پاراگراف‌ها با PDF تطبیق داده شده‌اند. از بازنویسی مضمون، تغییر ارقام مالی یا استنتاج اعتبار جاری مقرره پرهیز شده است. سایر نسخه‌های OCR و فایل‌های `content/cra/documents` دست‌نخورده باقی می‌مانند. واردسازی دوباره یک دسته قدیمی OCR نباید بازسازی‌های جدیدتر را از manifest حذف کند.

این الگو مجوز بازسازی حدسی همه PDFها نیست. اصلاح جهت نمایش و خطای فاصله‌گذاری رقم‌ها عمومی است، ولی بازسازی ساختاری هر سند باید به شاهد همان سند متکی باشد.
