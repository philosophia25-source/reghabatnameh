# رقابت‌نامه

شبکه تحلیلی نادر جعفری در حوزه حقوق رقابت و تنظیم‌گری ایران.

## معماری

- Next.js با App Router
- خروجی کاملاً استاتیک
- راست‌به‌چپ و فارسی
- انتشار خودکار روی GitHub Pages
- معماری شبکه‌ای میان قوانین، اجزای مواد، شرح‌ها، اسناد، نهادها، موضوعات و بازارها
- بدون دیتابیس، پنل کاربری یا سرویس پولی

## توسعه محلی

```bash
npm install
npm run dev
```

## ساخت خروجی استاتیک

```bash
npm run build
```

خروجی در پوشه `out` ساخته می‌شود.

هر تغییر در شاخه `main` پس از بیلد موفق به‌صورت خودکار روی GitHub Pages منتشر می‌شود.
