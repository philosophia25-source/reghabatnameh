# رقابت‌نامه

وب‌سایت شخصی نادر جعفری در حوزه حقوق رقابت و تنظیم‌گری ایران.

## معماری

- Next.js با App Router
- خروجی کاملاً استاتیک
- راست‌به‌چپ و فارسی
- انتشار خودکار روی GitHub Pages
- بدون دیتابیس، پنل کاربری یا سرویس پولی

## توسعه محلی

```bash
npm install
npm run dev
```

## ساخت خروجی استاتیک

```bash
npm run build
```

خروجی در پوشه `out` ساخته می‌شود.
